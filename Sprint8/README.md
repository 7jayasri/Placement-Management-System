# Sprint 8 – Asynchronous Apex

## Project
Placement Management System

## Sprint Objective
Learn asynchronous processing in Salesforce using Future Methods, Queueable Apex, Batch Apex, and Scheduled Apex.

## Topics Covered
- Synchronous Processing
- Asynchronous Processing
- Future Methods
- Queueable Apex
- Batch Apex
- Scheduled Apex
- Governor Limits
- Engineering Design Decisions

## Key Learning
- Decide when work should happen immediately.
- Move secondary work to the background when appropriate.
- Choose asynchronous technology based on the business requirement.
- Continue following Governor Limits and bulkification principles.

## Business Scenarios
- Notify external systems after application submission.
- Perform background processing after offer acceptance.
- Process large datasets using Batch Apex.
- Execute recurring jobs using Scheduled Apex.

## Outcome
Understood the purpose of Salesforce asynchronous processing and the situations in which Future Methods, Queueable Apex, Batch Apex, and Scheduled Apex should be used.
